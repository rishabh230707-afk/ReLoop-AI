# Browser demo screenshots

## Run the latest version

Download a fresh repository ZIP, extract it, and run `python3 web_app.py` inside the extracted folder. Your browser opens at http://127.0.0.1:8765. Keep the terminal open.

Do not run `python3 reloop.py gui` for the new design: that opens the previous desktop interface.
