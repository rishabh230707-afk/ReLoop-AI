# ReLoop responsible AI guidance

## Fairness
Inventory wording can affect text matching. Test requests with varied terminology and review missed needs across departments and schools. Do not infer a school's deprivation or rank people using sensitive personal data.

## Privacy
The demo uses fictional institutional records and collects no student or child personal data. Local model mode sends the question, retrieved excerpts and tool observations only to Ollama on this computer. A shared deployment would require authentication, access controls and a retention policy.

## Transparency
Show retrieved document names and source excerpts beside generated answers. Text similarity is a ranking score, not confidence. Models can misinterpret sources even when citation identifiers are valid. Ask a coordinator when evidence is missing or ambiguous.

## Human control
The agent may search inventory, retrieve guidance and estimate a reuse proposal. It has no transfer, purchase, email, shell or file-writing tool. Human inspection and an explicit confirmation in the normal transfer form are required to change stock.
